2 · Words to know

Scenario, case, main scenario, anchor years

Scenario case

One of three pathways, always in this order: Slower Transition · Base Case · Faster Transition.

Scenario

A named set of assumptions for all three cases. The Default Scenario is the permanent baseline and can't be overwritten.

Main scenario

The scenario a model's Forecasts page shows. There is one per model, shared by everyone.

Anchor years

Assumptions are set for 2025, 2030, 2035, 2040 and 2050. Growth rates hold until the next anchor; shares ramp in a straight line.

Every assumption is a percentage: type 5 for 5%. The editors accept any number, so check that shares add up to no more than 100%.

3 · The Forecasts page

Choose what to look at, top to bottom

  1. Scenario: which saved scenario drives the page. This changes the main scenario for everyone.
  2. Scenario case: one case, or tick Show all scenario cases to see the three side by side.
  3. Show: Sales / Fleet (vehicle models): new sales each year, or cumulative sales since 2020.
  4. Scenario configuration: open it to see the assumptions behind what you are looking at.

Then two sections of results

  • Sales by region & powertrain: BEV, PHEV and IC Only, with region and powertrain filters.
  • Sales by region (all LDV / HDV): the whole market per region, including the hybrids the model does not forecast.
  • Each section: View Chart or Table, and a Chart type.
  • Tick Include … (not forecast by this model) to show FHEV (LDV) or ICE and H2 hybrids (HDV), as GlobalData publishes them.

5 · Edit Scenario Configs

Edit, compare, then save

  1. Choose the scenario to start from.
  2. Edit the anchor-year values. One table per scenario case, side by side.
  3. Open "View …" under a table: the edited forecast is dashed ("– Updated"), the saved one solid.
  4. Save with one of the three buttons at the bottom.
ButtonWhat it does
Save new scenario to dashboardSaves the edits under a new name and makes it the main scenario
Save updates to scenarioOverwrites the scenario you are editing (not allowed for the Default Scenario)
Revert unsaved changesThrows the edits away

Nothing changes elsewhere in the dashboard until you save.

6 · Saved Scenarios

One page per scenario

  • Shows the scenario's assumptions for all three cases.
  • Set as main … scenario makes every page of that model use it.
  • Rename scenario changes its name in the sidebar.

Saved scenarios are fragile online

Everyone shares them, and the online app keeps them in temporary storage: a restart or redeploy wipes everything except the Default Scenario.

Keep a record of any scenario that matters: a screenshot or a download of its configuration tables.

7 · The Other Oil model

Same pages, sectors instead of regions

  • Filters choose sectors: Petrochemicals, Shipping, Aviation, Buildings/Power/Other.
  • Two sections: Oil consumption (mb/d) and Activity (billion tonne-km for shipping, billion passenger-km for aviation).
  • Activity is never stacked: tonne-km and passenger-km can't be added.
  • Charts start in 2022, the first year every series exists.

The levers you edit

YoYgrowth per year, stepped and compounded
PAefficiency change per year; negative = less oil per unit
Penetrationshare served by other fuels or electric, in a straight line

8 · Good habits

Before you share a result

  • Say which scenario and which case a chart shows; the page title and selectors tell you.
  • Check the filters: a "Global" line covers only what is selected.
  • Changing the main scenario changes it for everyone: tell the team.
  • Use the Table view and its download for exact numbers.
  • Remember the limits: projections, not predictions; "sales" are production; Fleet is not the vehicle stock.
