3 · The secrets file

The login, and the token if you download the data

Copy .streamlit/secrets.toml.example to .streamlit/secrets.toml and fill it in:

[auth] username = "choose-a-username" password = "choose-a-password" [github] data_repo_pat = "github_pat_..."
  • [auth] is the one login everyone uses to open the dashboard. You choose it.
  • [github] is needed only when a file is missing from input_data/: a fine-grained GitHub token with read access to the data repository only.
  • The file is ignored by git. Never commit it.
  • Online, the same keys go in the app's Settings → Secrets on Streamlit Community Cloud.

4 · Run it on your computer

Three commands

pip install -r requirements.txt cp .streamlit/secrets.toml.example .streamlit/secrets.toml streamlit run app.py
  1. Put the five files in input_data/ (the folder is ignored by git).
  2. Fill in the secrets file.
  3. Run the commands; the dashboard opens at http://localhost:8501.
  4. Sign in with the username and password from your secrets file.

Other ways

Dev container / Codespaces. .devcontainer/ sets up Python 3.11, installs the packages and starts the app on port 8501.

One model on its own. Each model runs from the command line and prints its results. Give the file path:

python ldv_forecast_model.py input_data/globaldata_ldv_sales.csv python hdv_forecast_model.py input_data/globaldata_hdv_sales.csv python other_oil_forecast_model.py

5 · Put it online

Streamlit Community Cloud

  1. Keep the five files in a private GitHub repository, and set DATA_REPO in data_loader.py to its name.
  2. Create a fine-grained token with read-only access to that repository. Note its expiry date.
  3. On share.streamlit.io, create an app from the code repository: branch main, file app.py.
  4. In the app's Settings → Secrets, paste [auth] and [github] data_repo_pat.
  5. Deploy, then check: the login blocks strangers, the data downloads, and the numbers match a local run.

If the code repository is private

  • The app is private by default: only people you invite can open it, on top of the login. You can make it public in its sharing settings.
  • Community Cloud allows one private app at a time.
  • You need admin rights on the repository to deploy from it.

The app follows main. A redeploy or restart wipes the scenarios users have saved online.

6 · Updating the data

Same file name, same columns, then restart

  • Replace the file in the data repository (or in input_data/) with a newer extract that keeps the same file name and column layout.
  • Restart the app so it downloads the new files.
  • Newer years move the forecast start only if FORECAST_START in forecast_model.py (now 2025) is changed too. Until then, extra years are treated as the source's own forecast and ignored.
  • Columns the code reads: REGION and HYBRID & EV TYPE (LDV), COUNTRY and POWERTRAIN TYPE (HDV), plus one column per year.
  • Editing a schema file changes that model's Default Scenario.
